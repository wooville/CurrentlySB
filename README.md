The repo.json file in our CurrentlySB repository communicates which n number and which sound bank each sample can be accessed from in Estuary. 

Instructions: This repository can be used through Estuary, which can be found at: https://estuary.mcmaster.ca/ 

Type this command into the Estuary terminal to add these samples: !reslist "https://wooville.github.io/CurrentlySB/repo.json"
